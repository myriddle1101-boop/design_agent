# 全站动效方案

## 1. 定位与边界

- 轮次：R4动效质量规划；主评价标准C5。
- 目标：不改变六个Tab、内容顺序、真实信息、项目入口、筛选、复制、下载和详情页架构，为全部既有操作建立统一、可理解、可降级的动效语言。
- 核心概念：一条被浏览行为唤醒的星光路径。
- 三种动作角色：路径动作负责滚动与阅读顺序；窗口动作负责状态确认；拼贴动作负责照片、卡片和装饰。
- 信息必须先存在，动效只增强解释；同一时刻只允许一个高显著性动作。

## 3. 动效Token

| 类型 | 建议值 | 用途 |
|---|---:|---|
| 即时状态 | 100–140ms | pressed、错误/成功颜色 |
| 快速反馈 | 160–220ms | hover、focus、下划线、箭头 |
| 标准切换 | 240–360ms | Tab指示、筛选、details |
| 内容进入 | 480–620ms | 标题、卡片、区块 |
| 场景动作 | 650–850ms | 照片落位、前景弹入 |
| 最大单次时长 | 900ms | 仅单个品牌焦点元素 |
| 子项错峰 | 45–70ms | 同组最多5项 |
| 标准缓动 | cubic-bezier(.22,1,.36,1) | 进入、位移 |
| 直接退出 | cubic-bezier(.4,0,1,1) | 离开、收起 |
| 装饰弹性 | cubic-bezier(.34,1.35,.64,1) | 仅贴纸、星点、后层卡 |

正文位移不超过12px、卡片20px、装饰32px；卡片旋转不超过±3deg，主内容缩放不低于0.98。

## 4. 全站交互方案

### 4.1 首次进入

1. 页面骨架和全部文字立即存在，不等待动画。
2. 复古浏览器框架在0–180ms内显现，不位移。
3. 当前Tab在120–260ms内点亮并出现下划线。
4. 页头按eyebrow→H1→摘要进入，总时长480–620ms，错峰60ms，Y位移8–12px。
5. 首屏照片或唯一主视觉随后80ms落位：scale 0.98→1，650ms。
6. CTA整体一次出现，不逐个长时间弹跳。
7. 同一会话再次切换Tab只执行简化页面转场。

### 4.2 滚动下翻

- 每个section只触发一次；顶部进入视口约75%时开始，快速越过时直接显示终态。
- 顺序为背景场景响应→标题进入→卡片错峰。
- 标题opacity 0→1、Y 12px→0，520ms。
- 卡片opacity 0→1、Y 18px→0，560ms，错峰60ms；每行最多3张。
- 白色星光路径随滚动局部显露，只改变装饰SVG描边，不改变布局。
- 天空→山→草地→溪水→花田的自然顺序保持不变。
- 远景速度差约1%–2%，前景2%–4%，单屏位移不超过24px；停止滚动后立即稳定。
- 禁止滚动劫持、强制吸附、横向替代纵向滚动和长时间固定内容。

### 4.3 Tab切换

六个Tab继续使用独立URL。

1. hover/focus：文字上移1px，底部星光线展开，180ms。
2. pointerdown/键盘激活：窗口硬阴影缩短2px，120ms。
3. 当前Tab底色切换，指示线220ms完成。
4. 旧内容只做opacity 1→0.96，120ms，不整体飞走。
5. 新页面导航框架保持稳定，页头执行360–480ms简化进入。
6. 前进/后退保持当前Tab正确；转场不得阻断历史记录。
7. View Transitions API不可用时直接导航。

### 4.4 按钮和链接

| 状态 | 动作 |
|---|---|
| hover | 背景/描边180ms；箭头平移3px；硬阴影缩短1px |
| focus-visible | 星黄焦点环立即出现，并执行等价箭头反馈 |
| pressed | scale 0.98、阴影压平，100ms |
| release | 160ms回到激活状态，不超过原尺寸 |
| 外部链接 | 下划线展开、箭头右上移2px |
| 下载简历 | 普通按钮反馈；不伪造下载进度 |
| mailto | 普通按钮反馈；不显示“发送成功” |

### 4.5 项目卡

- 默认始终显示图片、类型、日期、标题、说明和CTA。
- 进入视口：整卡Y 18px与opacity进入；文字不逐行飞入。
- hover/focus-within：主窗口上移4px；后方两层纸片平移8px/14px并旋转±2deg，320–420ms。
- 图片scale最多1.015，不缩放文字密集图。
- 标题栏装饰符号错峰35ms点亮；CTA下划线和箭头同步出现。
- 失焦220–300ms收回。
- 点击先执行100ms按压，正常进入详情；不得延迟导航超过120ms。
- 触屏保留静态层叠和按压反馈，不依赖hover。
- AI项目强调“窗口启动”；Portfolio的纸片层叠可略强，但共享同一时长和缓动。

### 4.6 筛选与卡片重排

不改变类别、URL参数和结果逻辑。

1. 按钮按下100ms，选中底色/边框180ms切换。
2. 不匹配卡片120–160ms淡出并scale到0.985后隐藏。
3. 保留卡片使用FLIP位移，在280–420ms到达新位置。
4. 新出现卡片220–320ms淡入，不重复完整入场。
5. 快速连续点击时取消上一动画，以最新筛选为准。
6. 减少动态时直接更新，仅保留≤120ms颜色变化。

### 4.7 Experience时间线和details

- 时间线主轴随当前阅读区逐段显露，不一次画完整页。
- 教育/经历卡沿路径方向轻移12px。
- summary的hover/focus点亮标题栏，展开符号180ms旋转90deg。
- 展开内容在260–360ms内显现；收起180–240ms。
- 焦点始终停留在summary。
- 深链或恢复状态时直接显示正确内容，不先折叠再播放。

### 4.8 项目详情

- 首屏按项目类型→标题→摘要→主图进入。
- 后续detail-section统一采用低强度显现。
- 长图和系统图只淡入240ms，避免缩放造成文字模糊。
- 当前没有图库拖拽功能，本轮不新增轮播、Elastic Stack或灯箱。

### 4.9 Contact与复制

- 星光路径在最终CTA附近收束。
- 复制邮箱后状态在150–220ms内切换，至少保持2秒。
- 成功允许一个星黄小星点在350ms内显现；不撒花。
- 失败直接显示错误文字和边框，不抖动。
- 焦点不移动，继续使用现有aria-live。

### 4.10 移动菜单与资源

- 菜单打开240–320ms、关闭180–240ms；Escape关闭并返回触发按钮。
- 图片预留尺寸，加载后180–240ms淡入；失败直接显示替代信息。
- 视频仍由用户点击加载，不自动播放。
- 页面不可见时暂停装饰动画。

## 5. 背景交互

背景只唤醒现有世界观，不承载新信息。

### 5.1 指针靠近星星

- 只在桌面精细指针启用。
- 指针进入80–120px范围时，最近1–3颗星提高亮度并移动2–5px，响应120ms，复位300–450ms。
- 星星保持pointer-events:none，不抢占链接和卡片。
- 不替换光标，不生成持续跟随光尾。

### 5.2 点击空白背景

- 只在明确空白背景触发一次直径≤48px星光波纹，420–600ms后消失。
- 不展开内容、不改变URL、不采集数据、不发声。
- 点击按钮、文字、卡片、导航时绝不触发。
- 如果实现时被判定超出功能边界，可删除此项；其他方案不受影响。

### 5.3 前后景

- 云层/远山最低速度差；草、花、芦苇只在首次进入时上浮8–16px，不持续摇摆。
- 溪水仅2–3条高光随滚动横移，不无限水波。
- 星光路径是全站唯一持续与滚动绑定的品牌动作。
- 项目卡展开时，背景响应降低到50%振幅。

## 6. 六个Tab强度分配

| Tab | 主角动效 | 次级动效 | 禁止 |
|---|---|---|---|
| Home | 星光路径引导、照片拼贴落位 | 代表卡错峰 | 多装饰循环、姓名逐字乱飞 |
| Experience | 时间线显露、details展开 | 窗口标题栏点亮 | 固定卡片、事实文字漂移 |
| AI Projects | 筛选后的卡片重排 | 窗口启动hover | 自动轮播、技术图3D倾斜 |
| Portfolio | 纸片层叠展开 | 图片轻微放大 | 每卡不同弹性、隐藏CTA |
| About | 照片和兴趣拼贴落位 | 少量贴纸弹入 | 持续漂浮、无关粒子 |
| Contact | 路径收束、复制反馈 | 低强度星点 | 撒花、音效、自动打开邮件 |

详情页统一低强度，避免作品证据被覆盖。

## 7. 冲突、降级与技术

### 7.1 冲突优先级

用户操作反馈 > 页面导航 > 当前区块进入 > 背景响应。

- 页面转场时暂停区块观察器，结束后再启用。
- 同一项目网格最多一张卡展开。
- 新操作取消旧动画并从当前状态继续，不排队。
- 动画不得修改文字、链接目标、筛选条件或DOM阅读顺序。

### 7.2 prefers-reduced-motion

- 所有内容初始可见。
- 关闭视差、路径绘制、星星靠近、波纹、弹性和旋转。
- Tab和筛选直接切换，只允许≤120ms颜色/透明度变化。
- details直接开合或短淡入。
- 卡片保留静态错位；hover/focus只改变描边和下划线。
- 背景交互永远不是理解内容或完成操作的必要步骤。

### 7.3 技术建议

- 基础反馈：CSS transitions。
- 区块进入：IntersectionObserver；无脚本时默认可见。
- 跨页Tab：View Transitions API渐进增强。
- 筛选：Web Animations API或轻量FLIP。
- 滚动路径：CSS自定义属性加节流的requestAnimationFrame，仅更新transform、opacity和stroke-dashoffset。
- details保持原生语义，用Web Animations API增强高度。
- 使用data-motion属性注册动作，不把内容写入动画脚本。
- 保持Astro静态架构；原生能力足够时不新增GSAP。

## 8. 实施顺序

1. 动效Token、减少动态开关和统一取消机制。
2. 按钮、链接、Tab、focus、pressed必要反馈。
3. 页面进入和跨页Tab转场。
4. 区块、标题、卡片进入。
5. 项目卡层叠与筛选FLIP。
6. Experience details与Contact复制。
7. 星光路径、前后景与空白背景反馈。
8. 六Tab、详情、404和移动菜单回归。
9. 正常动态与减少动态录屏并评分。

九步仍属于同一轮C5问题。任何一步造成A1、B1—B4失败或C4下降时必须修复或回退。

## 9. C5验收

建议达到4/5需同时满足：

- 所有既有交互都有明确、统一的状态反馈。
- Tab、滚动、卡片、筛选、details和复制使用同一时长/缓动体系。
- 星光路径成为滚动叙事主角，但不影响正文。
- 无自动轮播、滚动劫持、持续高显著性循环或无目的动效。
- 减少动态模式真实测试通过，核心内容不依赖动画。
- 用户能指出至少两处动效如何帮助定位、理解或确认操作。

必备证据：1440×900全站滚动录屏、六Tab切换、卡片hover与键盘focus、两类筛选、Experience开合、Contact复制、背景响应、减少动态同流程，以及构建/控制台/资源/链接/溢出回归结果。

## 10. 明确不实现

- 不改文字、图片、项目数量、区块顺序或信息架构。
- 不新增轮播、图库、灯箱、主题切换、音效开关或内容弹窗。
- 不做自动播放、滚动劫持、自定义光标、长加载开场或全屏遮罩。
- 不让背景星星展开新信息；这需要未来单独确认。
- 不以动效掩盖占位素材或创造虚构结果。
