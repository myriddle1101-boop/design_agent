# 视觉与动效规范

## 1. 文档定位

- 阶段：P3 视觉与动效规范。
- 目标：把静态参考图的视觉语言与动态参考页面的真实交互规律，转化为个人网站可执行、可测试、可降级的设计规则。
- 目标用户优先级：招聘者快速识别身份与能力 > 浏览项目证据 > 感受个人辨识度。
- 风格关键词：**自然幻想、活泼灵动、多巴胺但专业、手绘与数字界面共存**。
- 重要边界：静态参考图只支持视觉结论，不作为任何动效结论的证据；动效只依据四个链接的页面说明、可观察交互与实现源码。
- 素材策略：尚未补齐的内容可先使用明确标注的占位图；占位图不得伪装成真实项目截图或研究结果。

## 3. 总体视觉方向

### 3.1 核心概念：“一条会生长的星光路径”

网站以“路径”连接学习、实习、AI项目和设计作品：深蓝代表理性与技术，草绿代表成长和创造，星黄负责导航与强调，白色流线作为跨页面的识别性装饰。复古窗口与拼贴只用于项目卡、标签和局部信息框，让页面具有个人感，但不干扰招聘者扫读。

### 3.2 视觉层级

1. **信息层**：稳定网格、清晰标题、正文与事实证据，承担专业性。
2. **项目层**：作品图、窗口式卡片、标签与局部拼贴，承担差异化。
3. **氛围层**：星点、流线路径、植物或纸张纹理，承担情绪，不承载关键内容。

氛围层必须可移除；移除后，内容结构、阅读顺序和所有功能仍完整。

### 4.2 配色比例

- 60%：暖白或非常浅的蓝绿背景，保证阅读舒适。
- 25%：深蓝与草绿，用于大分区和导航定位。
- 10%：图片和项目自身色彩。
- 5%以内：星黄、荧光黄绿、橙色等高刺激强调色。
- 单一视口内最多保留 1 个主强调色和 1 个辅助强调色，避免“多巴胺”变成无优先级的彩色噪音。

### 4.3 对比度与状态

- 正文、小字号标签按 WCAG AA：普通文字对比度至少 4.5:1；大字至少 3:1。
- 荧光黄绿和星黄不得直接承载小号白字；优先配墨黑蓝文字。
- 链接不能只靠颜色识别，应同时有下划线、箭头或形状变化。
- `focus-visible` 使用 2–3px 星黄外环，并与组件边缘保持至少 2px 间距。

## 5. 字体规范

参考图提供的是“字体气质”而非可直接复用的字体文件，因此字体名称属于本站选型建议。

### 5.1 字体角色

| 角色 | 建议 | 用法 |
|---|---|---|
| 中文正文与界面 | `Noto Sans SC` / `思源黑体` | 导航、正文、按钮、项目说明；稳定、易读 |
| 英文与数字正文 | `Inter`，系统无此字体时回退无衬线 | 英文标题、年份、数据、标签 |
| 展示标题 | 优先使用粗体无衬线；局部可配一款有手写感的已授权字体 | 只用于短标题、引语或个人签名，不用于长段落 |
| 技术标签 | 等宽字体，如 `IBM Plex Mono` 或系统等宽 | AI、技术栈、年份、编号和窗口式元信息 |

### 5.2 排版层级

| 层级 | 桌面建议 | 移动端建议 | 字重/行高 |
|---|---:|---:|---|
| 首屏主标题 | 64–88px | 40–52px | 700–800 / 0.98–1.08 |
| Tab页标题 | 48–64px | 34–44px | 700 / 1.05–1.15 |
| 区块标题 | 32–44px | 26–34px | 650–750 / 1.15–1.25 |
| 卡片标题 | 20–28px | 19–24px | 600–700 / 1.25 |
| 正文 | 16–18px | 16–17px | 400–500 / 1.6–1.8 |
| 标签/元信息 | 12–14px | 12–14px | 500–650 / 1.35 |

### 5.3 字体迁移边界

- 可迁移：粗细反差、关键词荧光底、等宽标签、少量手写注释。
- 不迁移：参考图中的具体品牌字形、像素字的大段使用、为装饰而扭曲中文、过多字体混排。
- 一屏最多出现 2 个字体家族；手写风仅作点缀，不参与关键信息识别。

## 6. 布局与密度

### 6.1 网格

- 桌面：12列网格，内容最大宽度 1280px，左右安全边距 48–72px。
- 平板：8列，边距 32px。
- 移动端：4列，边距 20px；所有横向交互必须提供按钮或滑动提示。
- 主要文字列建议控制在 60–72 个中文字符的视觉宽度以内。

### 6.2 密度规则

- 首页首屏：低密度。只保留身份、方向、1段介绍、2个主CTA和个人照片。
- 经历页：中密度。时间线和数字卡可快速扫读，避免大幅装饰抢占空间。
- AI项目与设计作品列表：中高密度，但每个卡片必须有明确标题、角色、类型和入口。
- 项目详情：高低交替。图像密集区之后必须安排留白或短文本区，形成“浏览—理解—停顿”的节奏。
- 关于我和联系页：低至中密度，以个人气质与行动入口收尾。

### 6.3 长页面分区

从 S3、S4 迁移“场景化分段”的思路，但不复制活动页的持续高密度。建议每 2–3 个内容区切换一次背景明度或图形边界；切换只帮助定位，不把每个区块做成独立主题。

## 7. 形状、组件与图像语言

### 7.1 形状系统

- 主卡片：圆角 18–28px，暖白底，1–2px 墨黑蓝或深绿描边。
- 窗口式项目卡：保留简化标题栏、状态点或文件标签；不得照搬特定操作系统商标和控件。
- 图片框：方形、4:3、3:2 三种固定比例；同一列表只使用一种比例。
- 标签：胶囊或荧光贴纸形；适合项目类型、技术栈、年份，不放长句。
- 圆形入口：适合兴趣、能力或项目分类；不承担大段文本。
- 自然轮廓：波浪边界、路径曲线、植物剪影和星点仅用于分区边缘及空白区域。

### 7.2 图像语言

- 真实项目证据优先：界面、系统图、原型、研究结果、作品照片。
- 个人形象采用已确认生活照，裁成方图；允许用白色或荧光绿不规则边框形成拼贴感。
- 插画应采用颗粒、刷痕或纸张质感，避免光滑的通用3D人物和无内容关联的AI渐变球。
- 深蓝星空与绿色自然景观是品牌氛围，不应覆盖或篡改项目原图。
- 同一项目的图片色彩差异较大时，用统一框架、留白、标题条和标签协调，不强行套重度滤镜。

### 7.3 占位图规则

- 占位图必须显示“素材待补”或“Placeholder”，并写明计划内容，如“AI申根签移动端截图待补”。
- 使用固定比例、低饱和浅蓝/浅绿底、虚线框和简单线性图标。
- 不出现虚构数据、界面内容、合作方标志、用户评价或模拟奖项。
- 占位图在素材补齐后可一对一替换，不影响布局。

## 9. 动效系统总则

### 9.1 动效层级

1. **必要反馈**：按钮、Tab、焦点、表单和加载状态。必须实现。
2. **导航与空间关系**：项目轮播、卡片层叠、页面分区出现。适量实现。
3. **品牌氛围**：流线、渐变、水波、贴纸。仅在性能和可访问性允许时实现。

同一时刻只允许一个高显著性动效成为视觉主角。持续环境动效不得与阅读区的滚动出现动画叠加。

### 9.2 本站统一时长建议

| 类型 | 建议时长 | 节奏 |
|---|---:|---|
| hover/按压反馈 | 120–220ms | 快速 ease-out |
| 小组件展开/收回 | 240–420ms | 进入略有弹性，退出更快 |
| 卡片切换/轮播归位 | 450–700ms | 前快后慢，可保留轻微惯性 |
| 区块进入 | 500–800ms | 小距离、低错峰 |
| 品牌性弹性动效 | 700–1000ms | 仅用于单个焦点元素 |

这些是本站建议，不等同于参考项目的原始时长。

## 10. 动效规格

### 10.1 M1：无限3D渐变轮播

参考实现可确认：滚轮和横向拖拽改变轮播位置；松手后保留速度并以摩擦系数 `0.9` 衰减；卡片最大 Y 轴旋转约 `28deg`，最大纵深约 `140px`；当前卡色彩驱动背景渐变，渐变过渡 `0.45s power2.out`；初次进入动画 `0.6s power3.out`。本站不必复刻全部原值。

| 维度 | 本站规范 |
|---|---|
| 触发 | 桌面：横向拖拽、触控板横滚、上一项/下一项按钮；触屏：左右拖拽；键盘：左右方向键 |
| 状态 | 静止 → 拖拽中 → 惯性滑行 → 归位；切换时同步更新当前项目标题、序号和可访问状态 |
| 属性 | `translateX`、轻微 `rotateY`、`translateZ`/scale、背景渐变色；文字层不做3D倾斜 |
| 时长 | 拖拽时直接跟手；归位建议 450–650ms；背景渐变建议 350–500ms |
| 节奏 | 连续跟手、松手减速、最终吸附；不要自动播放 |
| 目的 | 在 AI Projects 中快速比较代表项目，并建立“路径/旅程”的空间感 |
| 使用范围 | 只用于首页代表项目或 AI Projects 顶部精选区，二选一；不用于所有列表 |
| 减少动态 | 关闭3D、惯性和渐变插值；改为可横向滚动的平面卡片或带按钮的淡入切换；保留标题、序号和CTA |

### 10.2 M2：Maxima式品牌互动

参考案例可确认：轮盘可拖拽或点击箭头切换；切换时暂停旧 SVG 动画，新分区可交互并更新路由；水面在鼠标移动时产生水波，源码示例时长 3 秒、`power2.out`；CTA 方形/圆形 morph 时长 0.9 秒并使用弹性缓动；点击标题切换贴纸，贴纸由 scale 0 到 1，时长 1 秒；滚动视差使用 ScrollTrigger 与滚动进度绑定。

本站不复刻完整轮盘、物理绳索或持续 Lottie 系统，只迁移低风险的“局部自然反馈”。

| 模式 | 触发 | 状态 | 属性 | 本站时长/节奏 | 目的 | 减少动态 |
|---|---|---|---|---|---|---|
| CTA形状反馈 | hover、focus-visible | 默认 → 激活 → 默认 | 圆角、轻微scale、箭头位移；不做复杂SVG morph | 180–260ms，轻快，退出更快 | 让CTA有生命感并强化可点击性 | 只改变底色、描边和箭头 |
| 星星/贴纸切换 | 点击明确控件 | 当前装饰 → 下一装饰 | opacity + scale，最多一个元素 | 350–600ms，轻微弹性 | 在 About 或项目结尾表达个性 | 直接替换，无缩放 |
| 路径/背景响应 | 指针移动或滚动进入 | 静止 → 局部响应 → 复位 | SVG控制点或背景位置，小振幅 | 响应连续；复位 600–1200ms | 强化“路径”品牌隐喻 | 固定为静态路径插画 |
| 区块显现 | 进入视口 | 未显现 → 已显现 | opacity、translateY 12–24px | 500–700ms；子项错峰 40–80ms | 帮助阅读分段 | 内容直接出现，不隐藏 |

### 10.3 M3：Stack Motion 项目卡悬停

参考页面明确标注为桌面 hover 效果，源码包含 10 种实验变化。共同机制是鼠标进入时让主卡后方多层彩色卡片通过位移、旋转、缩放或 Z 轴展开，离开时收拢；参考变化多使用 500–1000ms，部分弹性变化达到约 1200ms。

本站只采用一个统一、克制的版本，不能把10种效果混用。

| 维度 | 本站规范 |
|---|---|
| 触发 | `hover` 与 `focus-visible`；触屏首次点击不触发装饰动画，直接显示信息或进入详情 |
| 状态 | 默认层叠 → 预览展开 → 点击/激活；离开或失焦回到默认 |
| 属性 | 后层卡片 `translate` 8–20px、`rotate` ±2–5deg、轻微scale；主图只上移 2–4px，不模糊 |
| 时长 | 展开 320–480ms，收回 220–360ms；本站不沿用最长1200ms版本 |
| 节奏 | 后层依次错开 25–50ms；进入略有弹性，退出直接 |
| 目的 | 暗示一个项目包含多张过程图，同时提升作品集辨识度 |
| 使用范围 | Portfolio 项目卡；每屏最多两个正在展开的对象，通常只有当前hover项 |
| 减少动态 | 保留静态三层错位构图；hover/focus只改变描边和标题下划线 |

### 10.4 M4：Elastic Stack 拖拽卡组

参考实现可确认：只拖拽顶层卡；松手位置在横纵方向均未超过约 `200px` 时回弹，超过约 `450px` 时卡片移出并进入下一张；过渡为 `0.3s ease-out`，回弹使用带过冲的三次贝塞尔曲线；堆栈后三层位于 `0/-60/-120px` 的3D深度。

本站将交互简化为可发现、可控制的案例图库，不照搬像素阈值。

| 维度 | 本站规范 |
|---|---|
| 触发 | 拖拽顶层图片；同时提供“上一张/下一张”、缩略图和键盘方向键 |
| 状态 | 静止 → 拖拽 → 未达相对阈值回弹 / 达阈值换图 → 新顶层 |
| 属性 | `translateX/Y`、轻微rotate、opacity、层级；后层轻微上移 |
| 阈值 | 用卡片宽度比例而非固定像素：建议移动超过 25%–35% 或速度超过实现阈值才换图；R0后实测 |
| 时长 | 回弹 260–380ms；换图 320–500ms；不得拖延关键内容访问 |
| 节奏 | 跟手，松手后一次明确结果；不连续自动抛卡 |
| 目的 | 项目详情中浏览同一项目的过程图、界面与结果图 |
| 使用范围 | 只在素材数量至少3张的项目详情使用；不能作为跨项目主导航 |
| 减少动态 | 改成静态主图 + 缩略图列表；切换仅淡入或立即替换 |

## 11. 基础反馈与状态动效

| 组件 | 触发 | 状态/属性 | 时长 | 目的 | 减少动态 |
|---|---|---|---:|---|---|
| Tab导航 | 点击、键盘激活 | 指示条移动或宽度变化，文字颜色同步 | 180–240ms | 定位当前Tab | 指示条立即切换 |
| 主按钮 | hover/focus/press | 背景、描边、箭头 2–4px 位移；按下scale不低于0.98 | 120–200ms | 操作确认 | 只变颜色/描边 |
| 外部链接 | hover/focus | 下划线显现、箭头轻移 | 150–200ms | 告知跳转 | 只显示下划线 |
| 图片加载 | 资源到达 | 占位底色 → 图片淡入 | 180–300ms | 减少突跳 | 图片直接显示 |
| 视频 | 用户点击 | 封面 → 播放器；不自动播放 | 200–300ms | 保持控制权 | 无转场 |
| 表单/复制 | 提交或复制 | 文案与图标切换，状态保持至少2秒 | 150–220ms | 明确反馈 | 无位移动画 |
| 错误状态 | 校验失败 | 描边、图标、错误文字出现 | 120–180ms | 定位错误 | 禁止抖动，直接显示 |

## 12. 减少动态与无障碍

### 12.1 `prefers-reduced-motion: reduce`

启用时必须：

- 关闭3D旋转、惯性滑行、视差、水波、物理模拟、弹性过冲和连续背景运动。
- 关闭所有自动播放；视频和装饰动画只在用户主动操作后开始。
- 区块内容默认可见，不以动画完成作为可见条件。
- 轮播改为平面列表或立即切换；卡组提供按钮、缩略图和键盘操作。
- 必要状态变化可使用不超过 150ms 的颜色或透明度变化，或直接切换。

### 12.2 输入方式等价

- hover功能必须同时支持键盘焦点；触屏不得依赖hover才能看到CTA。
- 拖拽功能必须有按钮替代，并公开当前项序号与总数。
- 可点击卡片内部如果还有按钮，要避免嵌套交互冲突。
- 焦点顺序应与视觉顺序一致；轮播隐藏项不能进入Tab顺序。
- 动效完成后不得擅自移动键盘焦点。

### 12.3 性能边界

- 优先动画 `transform` 和 `opacity`；避免持续改变布局属性。
- 3D轮播和复杂背景只允许一个实例处于活动状态。
- 页面不可见时暂停 `requestAnimationFrame`、Canvas、Lottie和视频。
- 移动端优先减少同时出现的装饰对象和纹理分辨率，不牺牲正文清晰度。
- R0必须在固定视口检查滚动、交互与控制台；正式迭代中 B3、B4 继续作为硬门槛。

## 13. 迁移边界

### 13.1 可以迁移

- 深蓝星空、绿色自然、白色路径和星黄强调构成的颜色关系。
- 手绘/纸张肌理与结构化网页网格的对比。
- 复古窗口标题栏、拼贴边缘、荧光标签等局部组件语言。
- 轮播的拖拽与惯性逻辑、Stack的层叠预览、Elastic Stack的跟手和回弹逻辑。
- Maxima案例中“交互服务于叙事”的原则，以及小范围自然反馈。

### 13.2 不直接迁移

- 参考图中的品牌名称、标志、人物、插画、照片、具体字体文件和版权素材。
- 活动专题页的全页高密度、重复侧边导航、促销式按钮和大量竞争色。
- 依赖hover才能理解内容、没有键盘替代的拖拽、自动播放轮播。
- 同时复制3D轮播、轮盘、物理绳索、水波、十种Stack效果等全部演示功能。
- 静态插画中没有实际证据的星星闪烁、草木摆动、流线流动或视差。

## 14. R0实现优先级

### 必须实现

- 色彩、字体、网格、卡片、标签与占位图令牌。
- 六个Tab统一导航、焦点状态、按钮反馈与响应式布局。
- 内容和项目图片的静态清晰展示。
- `prefers-reduced-motion` 基础规则。

### 建议实现

- Portfolio 统一的克制版 Stack hover/focus。
- AI Projects 或首页二选一的平面优先轮播；桌面再增强3D。
- 小幅区块显现和CTA反馈。

### 延后验证

- 路径/水波式指针响应。
- Elastic Stack项目图库。
- 更复杂的Canvas渐变、SVG控制点或物理效果。

这些增强项应在网站内容、硬门槛和基础交互稳定后再开启；任何增强导致 B3 运行可靠性、B4 响应式完整性或可访问性下降时，应关闭或回退。
